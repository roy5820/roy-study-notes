# [Unity6] Claude Code CLI로 게임 개발부터 출시까지

## 섹션 1. 시
### 1. 강의 소개(CLI)
- 개발자 역할이 코더에서 디렉터로 바뀜
- 설계, 판단, 방향 제시가 개발자의 방향으로 바뀜
- 개발자는 AI를 효과적으로 디렉팅하는 역량이 중요해지며 아래 5가지가 중요해짐
  - 프롬프트 엔지니어링: AI에게 어떤 요청을 어떻게 내리는 가
  - 시스템 설계 능력: 전체 아키텍처를 설계하고 분해하는 능력
  - 코드 리뷰 & 검증: AI가 생성한 코드의 품질, 보안, 성능을 평가하는 비판적 사고력
  - 도메인 지식: 비지니스 맥락을 이해하고 실제 요구사항에 일치하는지 판단하는 능력
  - AI 도구 오케스트레이션: 여러 AI 도구들을 이용해서 복잡한 워크플로우를 구축하는 능력
