# Part 01. AI 시대, 왜 프로그래머에게 기획서가 필요한가
- 프로그래머가 ai에게 자연어로 명령을 내려 빠르게 프로토타입을 만드는 시대가 옴
- 그로인하여 명확히 무엇을 만들지 설명하는 능력이 중요해짐
- 해당 파트에서 성명하는 내용 3가지
  - 프로그래머가 왜 기획을 이해해야 하는 가
  - 기획자가 없는 프로젝트에서 어떤 문제가 발생하는 가
  - AI에게 일을 시키기 위해 왜 구조화된 상세 기획서가 필요한 가

 ## Chapter 01. 바이브 코딩 시대의 게임 개발 변화
 - 바이브 코딩의 탄생으로 게임 하나 만드는 데 소모되는 시간과 노력이 줄어듬
 - 바이브 코딩은 완벽한 설계 없이 빠르게 프로토타입을 완성할 수 있음
 - AI는 모호한 아이디어를 정확한 게임으로 바꿔주지 않음
 - 좋은 결과를 얻으려면 사람이 먼저 게임 규칙과 조건을 정리해야함
 - 즉, 프로그래머는 단순히 코드를 작성하는 사람에서 게임의 구조를 설명할 수 있는 사람이 되어야함
 - 이때 필요한 문서가 바로 프로그래머가 쓰는 게임 상세 기획서임
 - 이 책에서 말하는 상세 기획서는 만들 게임에 대해서 명확히 정리하고 AI 이해할 수 있는 형태로 게임을 설명하는 문서

## Chapter 02. 코드를 잘 쓰는 것만으로는 부족한 이류
- 코드를 아무리 잘 써도 무엇을 만들지 명확하지 않으면 좋은 코드도 방향을 잃음
- 기획은 '무엇을 만들 것이가'와 '왜 그렇게 만들어야 하는 가'를 정리하는 일
- 기획이 부족하면 매번 즉흥적으로 프로그래머가 판단하게 되며, 그 결과 기능이 추가될수록 코드 구조도 함께 무너짐
- AI를 활용하는 경우 해당 문제가 더 중요해짐
- 좋은 기획서에서 좋은 프롬프트가 나옴
- 프로그래머가 기획서를 작성해야하는 이유는 구현할 대상을 더 정확히 이해하고, AI와 협업할 때 더 좋은 결과를 얻기 위해서
