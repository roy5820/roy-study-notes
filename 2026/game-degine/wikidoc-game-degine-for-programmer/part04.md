# Part 04. 플레이어 조작과 캐릭터 기획하기
- 기본 조작부터 캐릭터 상태 머신, 애니메이션 전환 조건, 능력치 정의까지 플레이어 조작과 캐릭터 기획에 필요한 상세 기획서 작성법을 다룸

## Chapter 26. 조작 기획은 입력 명세에서 시작한다
- 입력 명세는 조작 기획에 출발점이며, 단순히 어떤 키를 사용하는 가 뿐만 아니라 입력을 어떻게 해석하는 가까지 정의해야함
- 대상 플랫폼과 입력 장치도 함께 고려해야함
- 키보다 행동을 먼저 정의하고 각 행동에 맞는 키를 플랫폼 별로 연결하는 것이 추후 키 설정 변경과 다른 플랫폼 지원할 때 유리함
- 입력이 발생하는 시점(눌렀을 때, 누르는 동안, 떘을 때)을 구분하여 정의해야 하며, 오래 눌렀는지에 따른 홀드 시간 규칙도 함께 명세에 작성해야함
